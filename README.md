◈ The Pillars of Sodium
I. The Grid (The Map of Pupli)
A 70-degree fixed-axis isometric interface. 400 nodes of pure potential. Each cell is a gateway to a private history, designed with a focus on tactile interaction and visual depth.

II. The Glass (The User Experience)
We’ve removed the clutter. What’s left is a "Walled Garden" of obsidian glass and light. High-density typography meets spatial computing, ensuring the interface disappears so the artifacts can speak.

III. The Spine (Server Concordia)
The central nervous system. Concordia manages the flow of data, authentication, and artifact synchronization. It is the invisible hand that keeps the ecosystem in perfect harmony.

◈ Operational Architecture
This repository contains the full system-stack for the Sodium ecosystem:

login.html: The gateway. Secure, minimalist, and designed to inspire.

index.html: The Planetary System. The 400-plot grid of Pupli.

museum.html: The Curation Engine. A 3D-spatial gallery supporting up to 7 curated artifacts.

admin.html: The Command Center. Manual authorization of the Concordia Spine.

spine.js: The "Brain." Unified logic linking the frontend to the vault.

◈ Technical Protocol
Logic: Javascript / Spine Architecture

Visuals: A-Frame 3D / CSS Obsidian Flow

Authentication: AES-simulated ID generation via Concordia

Curation: Max 7 objects per node to ensure digital scarcity and high fidelity.
